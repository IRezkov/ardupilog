# Определение прыжков в анализаторе логов

Анализатор оценивает наличие прыжков по телеметрии IMU. Это эвристика, а не
доказательство отрыва телеги от поверхности.

## Условия обнаружения

1. Выбирается группа IMU (`IMU`, `IMU2` и т. п.) с наибольшим количеством полных
   записей `TimeS`, `AccX`, `AccY`, `AccZ`.
2. Для каждой записи вычисляется модуль ускорения:

   `a = sqrt(AccX^2 + AccY^2 + AccZ^2)`

3. Кандидатом на свободное падение считается интервал, где `a < 3 м/с²`
   непрерывно не менее `0,08 с`.
4. Кандидат считается вероятным прыжком, если после этого в течение `0,8 с`
   модуль ускорения достигает `15 м/с²` или больше. Это интерпретируется как
   удар при приземлении.
5. Точки низкого ускорения остаются одним интервалом, если разрыв между
   соседними измерениями не больше `max(0,15 с, 5 × медианный период IMU)`.
   Кандидаты, начала которых разделены не более чем на `0,8 с`, объединяются.

В отчёте указывается начало интервала низкого ускорения относительно времени
старта лога. Если подходящих данных IMU нет, анализ помечается как
«не оценено».

## Ограничения

- Неровность или сильный удар могут дать ложное срабатывание.
- Прыжок может быть пропущен, если свободное падение слишком короткое,
  ускорение не опустилось ниже порога или нет подходящего удара при приземлении.
- Пропуски и ошибки измерений IMU влияют на результат.
- Отсутствие найденных событий не означает, что прыжков точно не было.

Пороги заданы в `functions/detect_log_jumps.m`; результат следует проверять по
графикам исходной телеметрии.

## Сигналы IMU в профиле графиков

В редакторе профилей доступны производные сигналы для визуальной проверки:

- для `IMU`, `IMU2` и других групп контроллера — модуль ускорения `|a|` в
  `м/с²` и индикатор низкого ускорения (`|a| < 3 м/с²`, значение 1/0);
- для каждого ID из `WIMU` — модуль ускорения `|a|` отдельно по колесу.

Поля ускорения `WIMU` записываются в сырых отсчётах датчика, а не в `м/с²`.
Поэтому для них отображается модуль в raw-единицах, без порога свободного
падения из алгоритма выше. Индикатор контроллерного IMU показывает только
условие низкого ускорения; для подтверждения события также проверяйте удар и
длительность интервала по описанным выше условиям.
